# CMS action safety matrix

Phase A static audit. “Safe today” means structurally safe for later authenticated use; **no action was executed against production**.

## Shared CMS runtime

| Page/component/action                   | Handler → service/repository                           | Target                           | Lifecycle / cache                                                                    | Affected rows confirmed?                           | Partial/public refresh risk                      | Safe today / exact fix                                                                                |
| --------------------------------------- | ------------------------------------------------------ | -------------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------- | ------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| Entity editor/list create/save/autosave | `saveDraft` → `create/update`                          | configured content table         | validate → mutation → module/home/search/public-key invalidation; autosave debounced | **Yes after Phase A shared gate**                  | version/audit callbacks can fail after core save | Safe primitive; B adds idempotent outbox                                                              |
| publish/unpublish/archive/restore       | handler → content-service transition → update          | configured table                 | status update then invalidation                                                      | Yes                                                | after-change hook can fail post-write            | Safe primitive; B surface partial-side-effect state                                                   |
| duplicate                               | handler → read/create                                  | configured table                 | copy draft then invalidate                                                           | create row yes                                     | related galleries are intentionally not copied   | Safe; label scope clearly in B                                                                        |
| permanent delete                        | former handler → repository remove                     | configured table                 | delete then invalidate                                                               | repository now checks rows, but normal UI disabled | references were not comprehensively verified     | **Unavailable in normal CMS.** Future elevated flow must satisfy two confirmations + dependency proof |
| cancel/discard                          | navigation/form reset                                  | none                             | local only                                                                           | n/a                                                | unsaved guard handles dirty forms                | Safe                                                                                                  |
| version restore                         | `VersionHistoryPanel` local restore then explicit save | `content_versions`, entity table | load snapshot; user saves                                                            | final shared save yes                              | snapshot record is best-effort                   | Safe with explicit save                                                                               |

## Cache inventory

Shared hooks invalidate `cmsKeys.module(module)`, `['home']`, `['search']`, `['search-page']`, and module-declared public keys. Bespoke pages use their own query keys (`homepage-hero`, gallery, timeline, contact, media-library) and require consolidation in Phase B. A toast must be emitted only after a mutation returns a row/count through `notifyAfterMutation` or a shared mutation hook; zero rows throw before `onSuccess`.
